# python-taxi-maintenance-fee-super
A Python OOP project demonstrating inheritance, constructor chaining using super(), and fare calculation by adding a 10% maintenance fee to a vehicle's base fare.
<br>
Topics Covered
<br>

1. Object-Oriented Programming (OOP) – Organizing programs using classes and objects.
2. Inheritance – Creating a Taxi child class from the Vehicle parent class.
3. super() Function – Calling the parent class constructor from the child class.
4. Constructor Chaining – Initializing inherited attributes using super().__init__().
5. Instance Attributes – Storing the base fare using self.base_fare.
6. Child Class Extension – Adding new functionality to the inherited class.
7. Percentage Calculation – Calculating a 10% maintenance fee.
8. Code Reusability (DRY Principle) – Reusing parent class initialization logic.
9. Type Hints – Specifying expected parameter and return types.
10. Docstrings – Documenting modules, classes, and methods.
11. Object Instantiation – Creating a Taxi object and calling its methods.
